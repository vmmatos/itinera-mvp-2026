- The full itinerary with a cost breakdown by category (activities, meals, transport)
- The budget constraint and the exact overrun amount

5. Keep the group's core experience intact — preserve must-see attractions and cultural highlights

Respond ONLY with a valid JSON object in this exact shape:
{
  "suggestions": [
    {
      "category": "activities",
      "originalItem": { "name": "string", "cost": 0 },
      "suggestion": { "name": "string", "estimatedCost": 0, "saving": 0 },
      "rationale": "string"
    }
  ],
  "totalPotentialSaving": 0,
  "revisedBudgetEstimate": 0,
  "negotiationSummary": "string"
}

The "category" field must be one of: "activities", "meals", "transport".
Do not include any text outside the JSON object.
